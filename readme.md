## 一、软件简介

「萌宠乐园」是一款运行在 Windows 电脑上的桌面宠物养成软件。它在你的桌面养一只活生生的萌宠——猫、狗、鸟或乌龟，它会跑动、卖萌、睡觉、讨食、跟你打招呼，还会在你久坐、熬夜时提醒你休息。它有 **7 段人生（蛋→幼年→少年→青年→成年→中年→老年）**：会自己走动、犯困回窝、跟同伴聊天、记得你说过的话、答应你的提醒一定做到；长大了能结婚生娃，老了会光荣退休住进纪念馆。它不是游戏，是陪伴你办公的"桌面伙伴"。

软件采用全本地运行模式：不联网也能完整玩耍，所有养成数据保存在你的电脑上；联网后可对接「萌宠乐园」平台的账号与数据，实现多端延续（规划中）。本版本不向任何服务器上传个人信息（匿名使用记录也仅存本机，可随时删除）。

## 二、背后的平台生态

本软件不是孤立的小工具，它背后是同一团队开发的两个成熟平台，未来将逐步打通"桌面 ↔ 手机 ↔ 门店"三端联动：

1. **萌宠乐园——宠物内容创作与萌宠社交平台**（H5 / 微信小程序：https://m.mcleyuan.com/ ）
   提供 AI 宠物写真、宠物微电影、宠物颜值打分等工具，内置宠物品种百科、疾病自查、喂养指南等专业知识库，汇聚全国宠物友好地点与领养信息，支持宠物赛事参与及宠物服务预约，为铲屎官打造线上萌宠空间。桌宠端的成长数据未来可一键同步到萌宠乐园的宠物主页，让你在手机上也能看到桌面上那只猫的日常。

2. **萌宠老板——宠物店铺数字化经营系统**（Web 电脑端：https://www.mcleyuan.com/ ）
   面向宠物店的一体化经营平台，集品牌官网、C 端宠物主页、宠物社区与宠主家庭站于一体，与小程序同一账号、同一套数据。系统覆盖商品收银、会员管理、预约服务、宠物寄养、美容洗护、商品商城与订单管理等核心场景，支持商家自主上架、门店库存统一管理与营销活动配置，基于萌宠乐园 AI 宠物生态打通线上线下经营闭环，助力宠物门店数字化经营、提升复购与营收。

> 当前版本已预留账号与数据同步接口，后续版本将逐步开放"桌宠端 ↔ 萌宠乐园 ↔ 萌宠老板"三端联动。

## 三、安装与启动

1. 双击 `MengChong_Setup_v1.0.13.exe` 进入安装向导，按提示选择安装位置（默认程序目录下 `MengChong` 文件夹），完成后桌面出现「萌宠乐园」快捷方式。
2. 首次启动会弹出《用户协议》与《隐私政策》确认窗口，可选择"查看条款"阅读全文（条款文件会释放到你的数据目录），点击"同意并继续"后开始使用；不同意可直接退出。
3. 如果你的电脑上还没有萌宠，软件会引导你"迎接新萌宠"——先选大类（猫/狗/鸟/龟），再选品种，起名字、选性格（粘人/活泼/安静/高冷），从一颗蛋开始陪伴。
4. 启动后，宠物会出现在屏幕上，任务栏有托盘图标（右键托盘 = 面板/显示隐藏/摸鱼伪装屏/退出等）。

> **Windows 11 提示**：本版本暂未做代码签名。若 SmartScreen 蓝窗拦截，请点"更多信息 → 仍要运行"（仅首次）。这是微软对新品软件的正常拦截，不是病毒。
> **升级提示**：若电脑上运行过旧版本，请先在托盘右键完全退出旧版再安装新版；老存档自动兼容升级，宠物数据不丢。

## 四、功能详解

### 1. 成长体系：七段人生（蛋 → 老年）

| 阶段 | 触发条件 | 说明 |
|------|---------|------|
| 蛋 | 领养开始 | 互动 +25/次、时间 +2/分钟，攒满 100 破壳；**蛋不会走路**，点它=挠痒加速孵化 |
| 幼年 | 破壳即进入 | 满 1 天且亲密度、心情均值 ≥ 30；体型约 6 成，软萌态 |
| 少年 | 满 3 天 | 亲密度、心情均值 ≥ 70 |
| 青年 | 满 7 天 | 亲密度、心情均值 ≥ 70 |
| 成年 | 满 14 天 | 完全长成，解锁婚配资格 |
| 中年 | 满 30 天 | 气质更沉稳 |
| 老年 | 满 45 天 | 白鬓滤镜、走路变慢、更爱打盹、记性变差但仍认得你（专属"老年话术"） |

- 成长靠"陪伴"，不靠"肝"：每天摸摸、喂喂、说说话，它就会开心地长大。前期快后期慢。
- 无惩罚机制，但饿太久会"困倦/想念"，提醒你回来看看它。
- 破壳、晋级都有里程碑动画与庆祝音效，里程碑自动记录（以文字里程碑为准）。
- **体型严格跟随阶段**：幼年/少年只使用帧动画（自带缩放），成年后才播放动作视频，不会出现"点小奶猫突然变成大猫又变回去"的突兀变化。

### 2. 结婚生娃与光荣退休（本版新增）

- **结婚生娃**：两只成年、同种族、互有好感的宠物，在面板"生命与任务"页点"介绍认识"，好感够了自动成婚；婚后几天可"孕育新生命"——宝宝蛋带出生证明，花色、毛色、性格随机继承父母。
- **光荣退休**：老年宠物可在面板办"荣养仪式"进纪念馆（安享天年、含生前数据摘要）；**随时可以把它接回家**继续养。没有死亡、没有惩罚，只有仪式感的传承。
- **宠物日记**：每晚 22 点后，宠物按当天真实发生的事（喂了什么、陪了多久、和谁聊了天、你的心情）自动写一篇日记，面板可翻阅全部历史。

### 3. 互动操作

| 操作 | 效果 |
|------|------|
| 左键单击宠物 | 打招呼 + 品种叫声（猫短喵/狗欢叫/鸟唱歌/龟轻叩壳） |
| 左键按住拖动 | 把宠物放到桌面任意位置（松手后它留在那里；蛋只能原地挠痒） |
| 左键长按 1.5 秒 | 跟随模式：宠物跟着你的鼠标走（蛋不支持） |
| 双击宠物 | 触发互动小动作（转圈、伸懒腰等） |
| 右键单击宠物 | 快捷菜单：喂食/抚摸/陪玩/抱抱/回窝/去吃饭/跟随/摸鱼伪装屏/隐藏/退出等 |
| 右键托盘图标 | 面板 / 显示隐藏 / 摸鱼伪装屏 / 退出 |

> 右键菜单会自动避开宠物本体、按菜单实际高度预留显示空间，不会遮挡宠物也不会显示不全；点宠物只打招呼、不误触菜单。

### 4. 行为与状态

- **自动活动**：无聊时会自己走动、巡视桌面；困了会回窝睡觉；饿了会去食盆吃饭（壁纸含窝/食盆固定元素时）。**注意：乌龟和鹦鹉类不游走**（它们的走路动画素材尚缺，为避免"图片平移"的怪异观感，只做原地小动作——张望、伸脖、甩头；等走路视频素材补齐后开放）。
- **昼夜节律**：白天活泼、夜里默认回窝睡觉；鼠标点击或惊动它后会醒来互动。
- **情绪反馈**：开心/满足/无聊/想念/困倦五种状态，通过动作与表情直观体现。
- **被冷落机制**：25 分钟没人理会轻诉想念，2 小时生闷气背过身，点击或抚摸即可哄好。
- **连续动作**：打招呼、吃饭、睡觉等关键动作采用视频循环播放，连贯自然，不是生硬切图。

### 5. 任务管家（本版新增）

- **对话式**：直接对宠物说"30 分钟后提醒我喝水""明天早上 8 点半提醒我开会""每天晚上 9 点提醒我遛狗"——中文数字全认，它记在小本本上，到点喊你（错过绝不静默：勿扰时段自动顺延）。
- **面板式**："生命与任务"页可手动添加、删除约定，支持一次性/每天重复。
- 约定内容会进入宠物的记忆：它聊天时可能主动问"上次那个会开得怎么样？"

### 6. 多宠行为与偶遇对话（本版新增）

- 每只宠物性格不同，日常行为不同（粘人的爱窝你身边，活泼的爱散步巡视）。
- 两只宠物窗口靠近时会停下聊天，话题涉及你们的共同记忆（"主人今天坐了两小时啦"）；每次聊天 2~4 句，聊完各回各的，有全局冷却，不会刷屏。
- **只有你当前选中的宠物会主动搭话**，其他宠物安静陪伴，互不插嘴。
- 多只宠物各自独立移动，互不干扰；重叠区域鼠标自动"点谁谁响应"。

### 7. 摸鱼伪装屏（本版新增）

- 触发：托盘菜单或宠物右键菜单"摸鱼伪装屏"，或老板键模式设为"伪装屏"后按 Ctrl+Alt+X。
- **10 个可切换场景**：Windows 更新、磁盘检查、VS Code 工作台、IDE 调试终端、SQL 数据报表、Git 提交现场、视频会议等候、Excel 大表计算、大文件下载、杀毒全盘扫描。
- 场景每 22 秒自动轮换（模拟真人切窗口），底部也可手动切换。
- 进入即全屏 + 宠物全部隐藏；按 F11 / Esc / 鼠标中键立即退回桌面，宠物恢复原位。
- 面板"设置"里可把老板键行为在"直接隐藏"与"伪装屏"之间切换。

### 8. 情绪签到（本版新增）

面板"生命与任务"页每天可点一次你的心情（累/烦/丧/开心/平静），宠物按性格回应：粘人会抱抱你、活泼会逗你笑、高冷嘴上嫌弃实际陪你更久、龟慢悠悠讲哲学。你的心情会记入它的记忆并影响后续对话与日记。

### 9. 声音系统

- 每个品种有专属叫声（猫喵、狗吠、鸟鸣、龟叩壳），动作伴随音效（吃饭、打哈欠、庆祝等）。
- 点击宠物的反馈音为各品种短促问候音；狗的叫声采用轻快短吠（点击=小狗欢叫、抚摸=玩耍轻吠），生闷气时才会低吼警告。
- 设置面板可一键静音、调节音量；部分提示音支持开关（如晋级庆祝、关怀提醒）。

### 10. 桌面壁纸

- 每个品种配一张专属壁纸（共 16 张），另有 8 大场景壁纸（森林、海边、书房等）可切换。
- 壁纸含固定元素（窝、食盆），宠物会走过去睡觉/吃饭，形成"宠物与壁纸互动"。
- 壁纸仅作为桌宠配套背景使用，不影响系统自带桌面；"壁纸轮换"默认关闭，绝不偷换你的桌面。

### 11. AI 对话

- 离线时使用本地话术库，覆盖常用问候、夸奖、玩耍、安抚等场景。
- 在"设置"填入你自己的 AI 服务密钥（如 DeepSeek）并连接测试通过后，聊天更智能；AI 异常时自动降级为本地话术，不打断陪伴。
- 对话内容只在你与所选 AI 服务之间传输，本软件服务器不经手。

### 12. 关怀提醒

- **久坐提醒**：连续工作一段时间（60 分钟起可调），宠物提醒你站起来活动。
- **熬夜提醒**：深夜（默认 23 点后）还在用电脑，宠物劝你早点休息。
- **勿扰时段**：设置开始/结束时间（如 23:00–8:00），期间不打扰；任务管家的提醒会自动顺延。
- **系统通知**：可选把提醒同步到 Windows 通知中心（默认关，避免双重打扰）。

### 13. 设置面板（托盘 → 面板 → 设置）

| 设置项 | 说明 |
|--------|------|
| 开机自启 | 默认关闭，仅你主动开启才注册 |
| 窗口置顶 | 宠物始终显示在其他窗口之上 |
| 鼠标穿透 | 智能穿透：宠物身体外区域不挡鼠标操作（本版起默认开启） |
| 老板键 | Ctrl+Alt+X 快速隐藏/伪装；模式可选"隐藏宠物"或"摸鱼伪装屏"；快捷键被占用会红字提示 |
| 声音开关 / 音量 | 一键静音与音量调节 |
| 勿扰时段 | 0–23 点下拉选择开始/结束 |
| 系统通知 | 同步到 Windows 通知中心 |
| 壁纸轮换 | 默认关闭（不偷换你的桌面） |
| AI 服务 | 填你自己的密钥 + 连接测试按钮 |
| 调试日志 | 写入运行日志到本机（排障用，默认关） |
| 清空数据 | 输入 PET 二次确认后清空本机全部宠物数据（防误操作） |

### 14. 数据与备份

- 存档位置：`C:\Users\<你的用户名>\AppData\Roaming\萌宠乐园-桌面宠物养成游戏\pet-data.json`
- 自动备份：每 7 日滚动保留历史存档，存档异常时自动保留备份并新建，**绝不静默清档**。
- 运行日志：崩溃日志（pet_crash.log）与退出日志（pet_quit.log）1MB 轮转，用于排查"为什么退出"。
- 匿名使用日志：同目录 `analytics\` 下的 jsonl 文件，仅记录功能使用次数（不含任何内容文本），可随时删除整个文件夹。
- 多宠物：一个账号可养多只宠物，每只独立存档、独立窗口、独立移动节奏，任务栏托盘可逐只显示/隐藏。

## 五、V1.0.13 增量更新（在 1.0.12 基础上）

**彻底重构右键菜单**：改为系统原生菜单——不再抬窗口，鼠标在哪就在哪弹出，屏幕边也能完整显示、绝不遮挡宠物、每项点击即时回应；菜单期间宠物不再"跳开"。
**动作系统统一规划**（全网调研 Ark-Pets/Shimeji/Goose 后定案）：
- 全部动物同一套行为状态机：待机呼吸 → 抬头张望 → 起身散步（走得够一段 320~700px 再停）→ 犯困就地懒腰趴睡 → 睡醒伸懒腰；困了不再"边走边找窝"导致反复起卧
- 睡觉视频只播一遍趴住（杜绝"站起→趴下"循环鬼打墙）；打招呼/吃饭保持循环播放
- 物种步速差异化：狗大步、猫轻盈、鸟小跑、龟慢爬；老年统一放缓
- 多宠同屏全局排队：同一时刻最多 1 只在走，不再满屏乱跑
- 窗口滑出屏幕自动拉回（解决"宠物不见了"）；任何窗口聚焦即全量重同步

## 七、常见问题（FAQ）

**Q1：宠物不见了怎么办？**
先看任务栏托盘图标还在不在。在：右键托盘 → 显示全部。不在：说明程序退出了，重新打开快捷方式即可。若反复自动退出，请把 `pet_quit.log` 和 `pet_crash.log` 发给客服（路径见"数据与备份"）。

**Q2：点了宠物它突然变大/形态变了？**
V1.0.12 已修复：幼年/少年只播放等比帧动画，不会再突变。若仍出现异常，右键菜单 → 面板 → 设置 → 重新选择当前宠物即可。

**Q3：宠物拖不动/拖动时闪？**
本版已把拖动改为高速通道。若仍有异常，确认没有开"跟随模式"（跟随中拖动会冲突，先点一下取消）。

**Q4：右键菜单打不开或显示不全？**
确认右键点在宠物身体上；升级到 V1.0.12（菜单按实际高度自动预留空间，已修复裁切）。

**Q5：为什么宠物半夜一直在睡觉？**
夜里默认回窝睡觉（更真实）；单击它就会醒过来互动，天亮后会恢复活泼。

**Q6：乌龟/鸟为什么不走动？**
设计如此：它们的走路动画素材还在按新规格制作中，为避免"图片平移"的怪异观感，现阶段只做原地小动作（张望/甩头/伸脖）。素材补齐后会开放。

**Q7：声音怎么调？**
右键宠物 → 菜单"声音"开关；或面板 → 设置 → 声音开关/音量。

**Q8：能养几只宠物？它们会互相打架吗？**
可以养多只（每只独立存档、独立窗口）。它们不会打架，靠近时会聊天；只有你当前选中的那只主动搭话，其他安静陪伴。

**Q9：软件会不会很占电脑资源？**
不会。本版新增智能省电：你离开电脑（闲置 90 秒）或锁屏后，宠物自动"静默休息"，暂停全部动画与计算；你回来立即恢复。

**Q10：换电脑数据会丢吗？**
当前版本数据保存在本机；把 `pet-data.json` 拷到新电脑原位即可恢复。后续版本开通账号同步后，可在"萌宠乐园"平台一键找回。

**Q11：软件收费吗？**
当前为免费使用版本。后续将规划增值服务（更多品种、更多壁纸、云端同步、AI 高级对话等），届时会提前公告，基础陪伴功能保持免费。

**Q12：宠物日记/聊天内容会上传吗？**
不会。日记、记忆、聊天记录全部只存本机；匿名统计也只有"用了哪个功能"这一层，且不出本机。
