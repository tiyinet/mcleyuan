## 一、软件简介

「萌宠乐园」是一款运行在 Windows 电脑上的桌面宠物养成软件。你在桌面上养一只活生生的萌宠——猫、狗、鸟或乌龟，它会跑动、卖萌、睡觉、讨食、跟你打招呼，还会在你久坐、熬夜时提醒你休息。它有 **7 段人生（蛋→幼年→少年→青年→成年→中年→老年）**：会自己走动、犯困就地趴下、跟同伴聊天、记得你说过的话、答应你的提醒一定做到；长大了能结婚生娃，老了会光荣退休住进纪念馆。它不是打发时间的游戏，是陪你办公的"桌面伙伴"。

**这一版最大的变化是"真实感"**：宠物的每个动作都由实拍级影像驱动，动作之间还有起身、停步、收手这些过渡，不再是几张图片来回切换。

## 二、背后的平台生态

本软件不是孤立的小工具，它背后是同一团队的两个平台，正在逐步打通"桌面 ↔ 手机 ↔ 门店"：

1. **萌宠乐园——宠物内容社区与本地生活平台**（电脑版：https://www.mcleyuan.com/park ）
   提供宠物圈、商城、比赛秀、品种图鉴、AI 写真/翻译/颜值打分等 12 款免费工具。桌宠端的成长档案可同步到平台，为你生成可查看、可分享的**宠物主页**。
2. **萌宠老板——宠物门店数字化经营系统**（电脑版：https://www.mcleyuan.com ）
   收银、会员、寄养、库存、预约、营销一体化，与小程序同一账号同一套数据。桌宠用户可在"云端同步"入口绑定手机号，成为宠物店与桌宠之间的桥梁。

> 三端使用同一套账号体系：在桌宠里绑定的手机号，可直接登录网站与小程序，反之亦然。

## 三、安装与启动

1. 双击 `MengChong_Setup_v1.1.1.exe` 进入安装向导，选择安装位置后一路下一步，桌面出现「萌宠乐园」快捷方式。
2. 首次启动会弹出《用户协议》与《隐私政策》确认窗口，可点"查看条款"阅读全文（条款文件会释放到你的数据目录）；点"同意并继续"开始使用，不同意可直接退出。
3. 若电脑上还没有萌宠，软件会引导你"迎接新萌宠"——先选大类（猫/狗/鸟/龟），再选品种，起名字、选性格（粘人/活泼/安静/高冷），从一颗蛋开始陪伴。
4. 启动后宠物出现在桌面，任务栏右下角有托盘图标（右键托盘＝菜单）。

> **Windows 11 提示**：本版本暂未做代码签名。若 SmartScreen 蓝窗拦截，点"更多信息 → 仍要运行"（仅首次）即可，这是微软对新发布软件的正常拦截，不是病毒。
> **升级提示**：如电脑运行过旧版本，请先在托盘右键完全退出旧版再安装新版；老存档自动兼容升级，宠物数据不丢。

## 五、成长体系：七段人生（蛋 → 老年）


| 阶段 | 触发条件   | 说明                                                                         |
| ---- | ---------- | ---------------------------------------------------------------------------- |
| 蛋   | 领养开始   | 互动 +25/次、时间 +2/分钟，攒满 100 破壳；**蛋不会走路**，点它＝挠痒加速孵化 |
| 幼年 | 破壳即进入 | 满 1 天且亲密度、心情均值 ≥ 30；体型约 6 成，走路是快速碎步、叫声偏奶       |
| 少年 | 满 3 天    | 亲密度、心情均值 ≥ 70；爱玩爱闹，动作轻快                                   |
| 青年 | 满 7 天    | 完全长开，精力最旺                                                           |
| 成年 | 满 14 天   | 解锁婚配资格；沉稳大步                                                       |
| 中年 | 满 30 天   | 气质更沉稳，毛色更深                                                         |
| 老年 | 满 45 天   | 白鬓滤镜、起身吃力、步子拖沓、更爱打盹、记性变差但仍认得你（专属"老年话术"） |

- 成长靠"陪伴"不靠"肝"：每天摸摸、喂喂、说说话就会长大，前期快后期慢。
- 无惩罚机制；饿太久只会"困倦/想念"，提醒你回来看看它。
- **体型全程平滑**：阶段之间体型是 0.8 秒缓动"长"过去的，静态图与动作影像使用同一套尺寸校准，不会再出现"点一下小奶猫突然变大猫"的突变。
- **步态随时龄变化**：幼年/少年步频更快（碎步）、老年步频放慢且窗口移动速度同步降低——不用看数字，看它走路就知道长大了还是老了。

### 成长仪式（V1.1.1 新增）

每次晋级，桌面会上演一场约 4.5 秒的仪式：

1. **铺垫**：它周身泛起金色脉动光晕，伴随上扬音效；
2. **爆发**：白光由内向外绽开、画面短暂定格，双层粒子与一声清亮的铃音；
3. **回味**：体型缓缓"长"到新阶段，头顶逐行浮出**成长证书**（如"肩高·体重·毛色已成长""解锁：沉稳大步"），并用它**当前阶段的叫声**叫一声。

老年"荣养"是另一套安静的仪式：柔光铺满、八音盒旋律、白鬓滤镜渐入，证书上写"时光给它镀上了白发""记得你的一切"。

## 六、行为与作息（它每天在桌面上做什么）

- **大部分时间安静坐着**：以静态待命与小动作为主（张望、舔爪、甩尾、伸脖），不会频繁乱走挡你操作。
- **散步**：点菜单"散步"，它会从原地起身、迈步走出去，**走 14~26 秒，撞到屏幕边缘自动掉头（面朝前进方向，不会倒退）**，点它就停下坐好。多只宠物**可以同时散步**，各走各的互不冲突。
- **吃饭**：就地摆开食盆低头吃，采用正放＋倒放的咀嚼循环，不会"跳回去再吃一口"，吃完抬头看你一眼。
- **睡觉**：困了就地趴下，睡觉影像只播一遍"趴下过程"，然后**定格在睡着的画面**（不反复重播）；白天小憩 15~25 分钟、夜间 40~70 分钟。**鼠标划过不会吵醒它，点它才醒**，醒来用一段独立的"起身"动作爬起来，而不是硬切回坐姿。
- **昼夜节律**：白天活泼，夜里默认回窝睡；23 点后仍在用电脑，它会提醒你休息。
- **五种心情**：开心 / 满足 / 无聊 / 想念 / 困倦。心情变化时头顶会短暂弹出对应小特效（💗 / 💫 / 💧 / 💤），约 5 秒自动飘散，不会一直挂着。
- **被冷落机制**：25 分钟没人理会轻诉想念；2 小时会背过身生闷气，点它或抚摸即可哄好。
- **发言有秩序**：多只同屏时，自动说话有全局排队，同一时间只有一只开口（你点谁，谁才回应你）。

## 七、结婚生娃与光荣退休

- **结婚生娃**：两只成年、同种族、互有好感的宠物，在面板"生命与任务"页点"介绍认识"，好感足够会自动成婚；婚后可"孕育新生命"——宝宝蛋带出生证明，花色、毛色、性格随机继承父母。
- **光荣退休**：老年宠物可在面板办"荣养仪式"进纪念馆（含生前数据摘要）；**随时可以把它接回家**继续养。没有死亡、没有惩罚，只有仪式感的传承。
- **宠物日记**：每晚 22 点后，它按当天真实发生的事（喂了什么、陪了多久、和谁聊了天、你今天心情如何）自动写一篇日记，面板可翻阅全部历史。
- **偶遇对话**：两只宠物靠近时会停下聊天，话题引用你们的共同记忆；每次 2~4 句，聊完各回各的，有全局冷却不会刷屏。

## 八、任务管家与关怀提醒

- **对话式**：直接对宠物说"30 分钟后提醒我喝水""明天早上 8 点半提醒我开会""每天晚上 9 点提醒我遛狗"——中文数字全认，它记在小本本上，到点喊你；勿扰时段会自动顺延，绝不静默吞掉。
- **面板式**："生命与任务"页可手动添加、删除约定，支持一次性 / 每天重复。
- **进入记忆**：约定过的内容它会记住，聊天时可能主动问"上次那个会开得怎么样？"
- **久坐提醒**：连续工作（默认 45 分钟起可调）后提醒你起身活动。
- **熬夜提醒**：深夜（默认 23 点后）劝你休息。
- **勿扰时段**：设置开始/结束时间（如 23:00–8:00），期间不打扰，提醒顺延。
- **系统通知**：可选把提醒同步到 Windows 通知中心（默认关，避免双重打扰）；宠物被隐藏时，提醒仍会通过系统通知送达。
- **情绪签到**：面板每天可点一次你的心情（开心/平静/疲惫/烦躁/低落），宠物按性格回应——粘人会抱抱你、活泼会逗你笑、高冷嘴上嫌弃实际陪你更久、龟慢悠悠讲哲学。你的心情会记入它的记忆并影响后续对话与日记。

## 九、摸鱼伪装屏与老板键

- **触发**：托盘菜单或宠物右键菜单"摸鱼伪装"；或把老板键模式设为"伪装屏"后按 Ctrl+Alt+X。
- **10 个场景**：Windows 更新、磁盘检查、VS Code 工作台、IDE 调试终端、SQL 数据报表、Git 提交现场、视频会议等候、Excel 大表计算、大文件下载、杀毒全盘扫描。
- 场景每 22 秒自动轮换（模拟真人切窗口），底部也可手动切换。
- 进入即全屏且宠物全部隐藏；按 **F11 / Esc / 鼠标中键**立即退回桌面，宠物恢复原位。
- **老板键（Ctrl+Alt+X）**：默认一键隐藏/显示全部宠物；也可在设置里改为"一键进伪装屏"。快捷键被其他程序占用时，设置页会红字提示。

## 十、声音、壁纸与装扮

### 声音系统

- 每只宠物按自己的物种发声（猫喵、狗吠、鸟鸣、龟叩壳）；动作有配套音效（吃饭、打哈欠、庆祝、落地）。
- **分龄音色**：幼年/少年声音偏尖（奶音），老年偏低哑、音量略轻——和体型变化一起构成"长大了"的听觉证据。
- 开机提示音改为与物种无关的轻快进场音，随后才按各自物种打招呼，不会出现"选的是鸟却响猫叫"。
- 单击/抚摸只响一声，不再叠两轨。
- 右键菜单"声音"或面板设置可一键静音、调音量。

### 桌面壁纸

- 每个品种配一张专属壁纸（16 张），另有家庭合影等场景壁纸可选；宠物"住在"自己品种的家园里。
- 壁纸含固定元素（右下角＝窝、左下角＝食盆），开"固定元素互动"后它会自己走过去睡/吃。
- **壁纸轮播默认关闭**，不会偷换你的桌面；开启后按你设的间隔（默认 60 分钟）轮换，随时可关。
- 切换当前宠物时，若开"壁纸跟随宠物"，系统壁纸自动换成它的专属壁纸。

### 装扮与百宝箱

- 可设毛色、性格；装扮箱/玩具箱/零食箱里的物品点选后自动进入**我的百宝箱**并持久记忆，重启不丢。
- 说明：装扮（蝴蝶结/围巾/帽子）在静态图片状态下会显示在宠物身上；动作影像播放期间影像本身无法叠加装扮，属当前素材形态限制。

## 十二、数据、备份与云端同步（请读完这一节）

### 本机数据

- 存档位置：`C:\Users\<你的用户名>\AppData\Roaming\萌宠乐园-桌面宠物养成游戏\pet-data.json`
- 自动备份：滚动保留历史存档；存档异常时自动保留原件并新建，**绝不静默清档**（会弹通知告知你）。
- 运行日志：崩溃日志（pet_crash.log）与退出日志（pet_quit.log）1MB 轮转，用于排查异常。
- 匿名使用日志：同目录 `analytics\` 下的 jsonl，仅记录"用过哪个功能"这一层，不含任何内容文本，可随时删除该文件夹。
- 本地备份：面板"数据与隐私"里的**导出档案 / 导入档案**——导出为 JSON 文本自行保存，导入时选择该文件即可恢复（含宠物、装扮、成长记录）。

### 云端同步（V1.1.1 起默认开启）

- **它做什么**：软件为本机自动创建一个专属云账号，把**宠物档案**（成长阶段、亲密值、里程碑、装扮选择）备份到云端，用途只有一个——换电脑、重装系统后能一键找回你的萌宠。存档变化约 8 秒内自动上传，另有约 90 秒一次的在线心跳。
- **它不做什么**：你的**对话内容、宠物日记文字、相册照片、本机任何文件、账号密码**都不上传；不做任何行为广告追踪。
- **怎么关**：面板 → 系统设置 → 数据与隐私 → "云端同步存档"开关，关闭后停止一切上传（已登录会话同时注销）。
- **怎么绑手机号（推荐）**：数据与隐私卡里的"绑定手机号"，填手机号＋自设密码（≥6 位）。绑定后：
  - 换电脑时装软件、输同一手机号密码，宠物自动找回；
  - 可用同一手机号密码登录**萌宠乐园网站与小程序**，看到同一只宠。
- **传输安全**：全程 HTTPS 加密，数据按账号隔离访问。
- 完整表述见《隐私政策》《用户协议》，与软件内条款一致。

### 清空数据

"清空本机全部宠物数据"需**三重确认**（弹窗确认 → 输入确认码 PET → 执行），只清本机，云端存档需另行管理。

## 十六、常见问题（FAQ）

**Q1：宠物不见了怎么办？**
先看托盘图标还在不在。在：右键托盘 → 显示全部。不在：程序退出了，重开快捷方式即可。若反复自动退出，把 `pet_quit.log`、`pet_crash.log`（路径见第十二节）发给客服。

**Q2：点它/摸它时它会突然变大或变小？**
V1.1.1 已按品种×动作逐条校准尺寸，静态图与动作影像一致。若仍见异常，请记下"哪个品种＋哪个动作"发给客服，这类问题改一个数值即可修正。

**Q3：右键菜单会挡住宠物/显示不全/点了没反应？**
本版菜单已改为系统原生弹出，鼠标在哪在哪弹、贴边也完整可见，且不会遮挡宠物本体。

**Q4：乌龟/鸟为什么不走了？**
本版已开放：16 个品种（含四种龟、四种鸟）都会真实迈步散步。若某只仍不走，多为该品种起身片段缺失，会自动跳过起身直接迈步，不影响散步。

**Q5：它半夜一直在睡，正常吗？**
正常。夜里默认回窝睡，鼠标划过不会吵醒它（V1.1.1 起悬停不唤醒），点它才醒；白天小憩 15~25 分钟、夜间 40~70 分钟。

**Q6：会不会很占电脑资源？**
它以静态待命为主，动作影像按需播放；闲置 90 秒或锁屏后自动"静默休息"暂停全部动画与计算，回来即恢复；还有"安静模式"可彻底定格。若你在远程桌面/老显卡环境，影像层异常时会自动回退静态图，不会白屏。

**Q7：声音怎么关？它会一直叫吗？**
右键菜单"声音"即关，或面板调音量。叫声有节流（同种连续叫最短间隔数秒、夜间音量自动降低），不会吵你。

**Q8：能养几只？会互相打架吗？**
可养多只，各自独立存档与窗口；不会打架，靠近会聊天，说话有排队不会几只同时开口；它们还能结婚生娃。

**Q9：软件收费吗？**
当前免费使用，基础陪伴功能永久免费；无广告、无弹窗、不强制注册。后续增值服务（更多品种、壁纸、AI 高级对话等）会提前公告。

**Q10：换电脑数据会丢吗？**
不会。云端同步默认开启，新电脑装好软件会自动找回；也可用面板"导出档案/导入档案"做纯本地迁移。

**Q11：日记、聊天记录会被上传吗？**
不会。云备份只包含宠物档案字段（成长阶段、亲密值、里程碑、装扮），对话内容、日记文字、相册一律不出本机，且云同步可随时在设置里关闭。

**Q12：安装时提示"Windows 已保护你的电脑"？**
未签名新软件的常规提示，不是病毒。点"更多信息 → 仍要运行"继续即可；本软件不捆绑任何第三方程序。
