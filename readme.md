一、它是什么
════════════════════════════════════════════════════════

「萌宠乐园 · AI 桌面宠物养成游戏」是一款运行在 Windows 电脑桌面上的
养成软件。你在桌面上养一只活生生的萌宠——猫、狗、鸟或乌龟，它会走会睡
会撒娇，眼神跟着你的鼠标转，饿了自己去食盆，困了就地趴下。

它有完整的 7 段人生（蛋→幼年→少年→青年→成年→中年→老年，约 45 天走完）：
记得你说过的话、答应你的提醒一定做到、长大了能结婚生娃、老了光荣退休进
纪念馆。它不是打发时间的小游戏，是陪你办公学习的"桌面伙伴"。

零压力承诺：永远不会饿死、病死、走丢；不登录也能玩；数据只存你电脑；
无广告、无弹窗、不逼氪。

六、常见问题
════════════════════════════════════════════════════════

  Q 双击安装包说"已有实例在运行"？
  A 程序只允许开一套（防止双开冲突）。右下角托盘退出旧版再装。

  Q 装完宠物没出现？
  A 看右下角托盘图标（可能被系统折叠进"^"里），右键→萌宠面板→
    确认"宠物显示"开启。

  Q 升级后宠物不见了？
  A 数据在 %APPDATA%\MengChong 里，卸载重装不会动它。若你卸载时
    勾选过"删除应用程序数据"，用面板【导入档案】从备份恢复。

  Q 换电脑怎么带走宠物？
  A 旧电脑面板【导出档案】→ 新电脑【导入档案】选那个文件，
    导入后应用自动重启，宠物当场回来。

  Q 面板开着变白屏了？
  A 本版有白屏自动恢复（15 秒内重建）；若长时间无响应，托盘退出
    重开即可，数据不丢。

  Q 定制宠物多久能好？不满意怎么办？
  A 24~48 小时出初稿，不满意免费重做一次；未开始制作可全额退款。

  Q 会不会很占电脑资源？
  A 待机时自动省电休眠（CPU 趋近 0），面板用完即销毁；
    实测 5 只同屏主进程约 50~60MB。
